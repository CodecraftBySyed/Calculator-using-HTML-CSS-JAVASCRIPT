# Simple Calculator

A clean, user-friendly calculator web application built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Support for parentheses to handle complex expressions
- Clean, modern UI with responsive design
- Clear button to reset calculations

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)

## Preview

The calculator features a sleek design with:
- A display screen showing current input and results
- Numeric keypad (0-9)
- Operation buttons (+, -, *, /)
- Support for decimal points
- Parentheses for complex expressions
- Clear button to reset

## Installation

No installation required! Simply download the HTML file and open it in any modern web browser.

## Usage

1. Click numeric buttons to enter numbers
2. Use operation buttons to perform calculations
3. Press "=" to compute the result
4. Press "C" to clear the display and start over

## Customization

The calculator can be easily customized by modifying the CSS styles:
- Change the color scheme
- Adjust button sizes and layouts
- Modify fonts and spacing
